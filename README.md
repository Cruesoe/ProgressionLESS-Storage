# ProgressionLESS: Storage

**All the Progression goodness, less research.**

Integrates storage mods into vanilla progression, so each storage building unlocks in its proper tech era.

The "LESS" is less research: Progression: Storage adds up to 22 research projects depending on your storage mods. This fork cuts that to at most 4, one per era: basic storage (Neolithic), crates and chests (Medieval), display pod (Spacer) and manipulator beam emitter (Ultra). Industrial storage uses the vanilla research it already builds on. Every building stays in the same era, and still needs the other research it did before.

Forked from [Progression: Storage](https://steamcommunity.com/sharedfiles/filedetails/?id=3292746186) by ferny. Huge thanks to ferny for the original mod and all the Progression work this builds on.
